📊 Data-Driven Social Engagement Analysis

Turning Social Media Data into Meaningful Insights

📌 Project Overview

The Data-Driven Social Engagement Analysis project focuses on understanding audience behaviour and analysing YouTube content performance using Data Science, Statistical Analysis, Natural Language Processing (NLP), and Machine Learning.

The project explores how viewers interact with videos, what people feel about content, and how engagement patterns can help identify high-performing videos.

🎯 Project Objectives

- Analyse YouTube video performance.
- Calculate video engagement rates.
- Understand audience sentiment through comments.
- Identify positive, negative, and neutral feedback.
- Predict high-engagement videos using Machine Learning.
- Develop an interactive dashboard for data visualization.

📂 Dataset Information

Two datasets were used:

1. USvideos.csv – 3,000 video records and 16 columns.
2. UScomments.csv – 574,789 raw comments and 4 columns.

After data cleaning, 399,328 comments remained for sentiment analysis.
